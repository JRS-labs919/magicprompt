# Variant F — General

Universal template only. Most useful additions when they apply:

```
FORM
<length, structure, inline versus file, level of detail>

AUDIENCE
<who reads this — changes register, assumed knowledge, and what gets defined>

WHAT I ALREADY KNOW
<so it doesn't get re-explained>
```

For a SHORT prompt, keep TASK, UNKNOWNS, and OUTPUT and drop the rest — a six-line prompt that gets read beats a thirty-line prompt that gets skimmed.
